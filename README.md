# SchoolLifeComplex 校园兴趣社区

面向本校在校生的校园兴趣社区。以兴趣板块为组织单元，承载内容交流、组织（社团/兴趣小组）阵地与信息互助。

## 一句话定位

> 一个让校园里的兴趣小组和注册社团都拥有自己阵地的社区平台：所有人可浏览与搜索，加入后即可参与，正式组织获得认证标识。

差异化主张是**组织入驻**：任何有管理者的群体（含学生自建的兴趣小组）都可以开设板块，正式注册社团额外获得认证标识与官方阵地。

## 五个功能模块

| 编号 | 模块 | 一句话说明 |
| --- | --- | --- |
| M1 | 身份与准入 | 注册、校园身份认证状态、个人主页、权限与信誉 |
| M2 | 兴趣板块 | 板块创建、分类、发现、加入、板块内自治 |
| M3 | 内容交流 | 发帖、回帖、点赞收藏、举报、版主审核、封禁 |
| M4 | 组织与活动 | 组织认证入驻、认领板块、组织主页、招新与活动发布 |
| M5 | 信息互助 | 失物招领与认领、校内公告与通知订阅 |

## 运行演示工程

需要 Node.js 18.18 及以上版本。

```bash
cd demo
npm install
npm run build
npm run start
```

浏览器打开 `http://localhost:3100`。预置演示账号见 [docs/演示说明.md](docs/演示说明.md)。

`demo/data/db.json` 是本地运行时数据，不在版本控制内；需要重置时执行 `npm run reset`。

## 术语约定

- **组织**：任何有管理者的群体。学生自建的兴趣小组与注册社团同属"组织"，后者额外获得认证标识。
- **板块**：内容组织的基本单元，归属于创建者；可被已认证组织认领为官方阵地。
- **双通道**：学生可自由创建板块；组织通过认证后认领或开设官方板块。
- **加入**：成为板块成员。浏览与搜索对所有人开放，发帖需先加入。
